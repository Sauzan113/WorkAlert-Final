# Analysis Phase – System Proposal (WorkAlert)

The Analysis Phase defines who uses WorkAlert, what the system does, and where and when it is used. Together, the deliverables in this folder form the **System Proposal**:

* **[Requirements Determination](./Requirements%20Determination/README.md):** Functional and nonfunctional requirements, documented in [WorkAlert_SRS_Version_2.docx](./Requirements%20Determination/WorkAlert_SRS_Version_2.docx) and tracked in [RTM_WorkAlert.xlsx](./Requirements%20Determination/RTM_WorkAlert.xlsx).
* **[Use Cases & Process Models](./Use%20Cases%20Process%20Models/README.md):** Use case descriptions and Data Flow Diagrams (DFDs).
* **[Data Model](./Data%20Model/README.md):** Entity Relationship Diagram (ERD) and entity/attribute definitions.
