# Use Cases & Process Models – WorkAlert

## Major Use Cases

| Use Case ID | Use Case Name | Primary Actor | Brief Description |
| :--- | :--- | :--- | :--- |
| **UC-01** | Register / Log In | Job Seeker, Employer | User creates an account or authenticates into the platform. |
| **UC-02** | Search Nearby Jobs | Job Seeker | Applicant searches and filters active job postings by geographic area. |
| **UC-03** | Post a Job Opening | Employer | Employer publishes a new local job listing with role details and location. |
| **UC-04** | Apply & Message Employer | Job Seeker | Applicant submits interest for a job and initiates direct chat with the employer. |
| **UC-05** | Review & Reply to Applicants | Employer | Employer views incoming applications and responds to applicant messages. |
