# WorkAlert – Location-Based Job Search & Employer Messaging Platform

WorkAlert is a full-stack web application designed to help job seekers discover nearby employment opportunities and communicate directly with local employers. This repository serves as our electronic project binder structured according to *Systems Analysis and Design* (8th Edition).
