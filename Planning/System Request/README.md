

# System Request – WorkAlert

- **Project Sponsor / Course Instructor:** Professor Ibrahim Musa
- **Project Leader:** Saujan Neupane
- **Project Team Size:** 6 members

**Business Need:**  
Local job seekers and small businesses lack a streamlined, location-focused platform to post nearby job openings and communicate directly in real time without lengthy application portals.

**Business Requirements:**
- Allow job seekers to search and filter employment opportunities in nearby geographic areas.
- Enable applicants to apply for listings and message employers directly within the platform.
- Allow employers to create accounts, publish job postings, and manage applicant messages.

**Business Value:**
- **Tangible Value:** Reduces hiring turnaround time for local businesses and eliminates job search friction for nearby applicants.
- **Intangible Value:** Improves local employment accessibility, direct applicant-employer transparency, and user engagement.

**Special Issues or Constraints:**
- Must be completed within the university semester schedule by the six-member development team.
- Must protect user personal data and authentication credentials securely.
