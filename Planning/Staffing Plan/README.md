## Project Charter

**Project Objective:**  
The WorkAlert project team will analyze, design, and build a full-stack web platform that enables job seekers to search for nearby employment opportunities and communicate directly with employers.

**Team Ground Rules:**  
The WorkAlert project team members agree to:
1. Attend a weekly team status meeting to review completed tasks and assign upcoming work.
2. Update task progress and push deliverables to the GitHub repository before scheduled deadlines.
3. Communicate technical blockers or schedule delays to the team as soon as they are detected.
4. Support teammates when help is needed on critical path deliverables.
5. Notify the team group chat whenever major documents, diagrams, or code updates are committed.
